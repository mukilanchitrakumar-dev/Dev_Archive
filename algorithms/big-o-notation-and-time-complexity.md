# Big-O Notation and Time Complexity

## Question

What is Big-O notation and why is time complexity important?

## Short Answer

Big-O notation is a mathematical framework used by software engineers to describe the asymptotic upper bound on how an algorithm's execution time or memory footprint scales as input size N grows toward infinity. It abstracts away hardware clock speeds, CPU architectures, and compiler optimizations to compare algorithmic efficiency objectively. Common complexities include O(1) for constant-time access, O(N) for linear scans, and O(N log N) for efficient comparison sorts.

## Simple Example

Scanning an unsorted array of N elements one by one takes O(N) linear time. Accessing an element in an array by index takes O(1) constant time regardless of array size.

## Key Point

Big-O measures how an algorithm's runtime or space scales proportionally as input size increases.
